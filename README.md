# Employee-Salary-Management-System

A simple Python + SQLite program to manage employee salary records. Add new employees and view the full list.

## Features
- Add employee (name + salary)
- View all employees
- Data stored permanently using SQLite

## Technologies Used
- Python 3
- SQLite3

## How to Run
1. Make sure you have Python installed (version 3.x)
2. Run the script:
   ```bash
   python main.py
